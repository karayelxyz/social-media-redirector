# Store listing images

Every file here is a 24-bit PNG with no transparency, rendered from the real popup and the
landing page palette (`Extension/popup.html`, `index.html`).

| File | Size | Where it goes |
|---|---|---|
| `screenshot-1-redirect.png` | 1280×800 | Screenshot 1 — Chrome, Edge, Firefox AMO |
| `screenshot-2-popup.png` | 1280×800 | Screenshot 2 |
| `screenshot-3-instances.png` | 1280×800 | Screenshot 3 |
| `screenshot-4-platforms.png` | 1280×800 | Screenshot 4 |
| `promo-440x280.png` | 440×280 | Chrome small promo tile, Edge small promo tile |
| `promo-1400x560.png` | 1400×560 | Chrome marquee tile, Edge large promo tile |
| `logo-300x300.png` | 300×300 | Edge Add-ons store logo |
| `icon-128x128.png` | 128×128 | Chrome/Edge/Firefox store icon (same file the package ships) |

Notes:

- Chrome Web Store accepts 1280×800 or 640×400 and wants 1–5 screenshots; upload all four in order.
- Edge wants screenshots at 1280×800 and a dedicated 300×300 logo.
- Firefox AMO only asks for screenshots; 1280×800 is its recommended size.
- The screenshots show the front-ends by name, not other sites' UI. Nothing here is a mock of a
  logged-in session.
