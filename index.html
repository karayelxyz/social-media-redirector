Social Media Redirector

Read Instagram, X, TikTok and Threads without an account. Every page you open is forwarded to a front-end that serves it without a login wall.

What it redirects

Instagram

instagram.com→kittygram

Posts, reels, stories, tagged and profiles.

X

x.com→shitter (nitter fork)

Timelines, posts, hashtags and profiles.

TikTok

tiktok.com→free front-ends

Profiles and videos.

Threads

threads.com→shoelace

Posts and profile pages.

Install

Download the build from GitHub releases, then load it by hand:

  1. Chrome / Edge: open chrome://extensions → Developer mode → Load unpacked for the unzipped folder, or drag the .crx onto that page.
  2. Firefox: open about:addons, click the gear icon → Install Add-on From File and pick the .xpi.

Hand-installed builds do not update themselves.

Bookmarklet

Not part of the extension: a bookmark that forwards the page you are on, one click at a time.
