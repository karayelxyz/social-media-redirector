Installation

Manual (developer mode)

Chrome:

  1. Download the latest release (zip or crx)
  2. Open chrome://extensions/
  3. Enable Developer mode
  4. Click Load unpacked and select the social-media-redirector folder

Firefox:

  1. Download the latest release (signed .xpi)
  2. Open about:addons
  3. Click the gear icon → Install Add-on From File
  4. Select the .xpi file

Bookmarklet

Works on any browser (Chromium or Gecko based). Create a new bookmark with the generated URL below. Then visit a supported page (Instagram, X, TikTok, or Threads) and click the bookmark — you'll be automatically redirected to the front-end.
